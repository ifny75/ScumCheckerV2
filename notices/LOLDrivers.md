The generated scanner/VulnerableDriverData.h contains detection metadata derived
from https://www.loldrivers.io/api/drivers.json (magicsword-io/LOLDrivers).
Upstream license: Apache-2.0; see LOLDrivers-LICENSE.txt in this directory.

Only records marked verified and categorized as vulnerable drivers are included.
This is a reduced and sorted derivative of the upstream data; no driver binaries
or exploit code are included. The source snapshot digest is recorded in the header.
Refresh with: python scripts/update_driver_indicators.py
